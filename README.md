Crumble Cafe
Одностраничное приложение (SPA) для уютной кофейни.
Что реализовано в проекте:
Уровень 1. Базовые доработки
   **Навигация без перезагрузки:** Реализовано переключение между тремя вкладками («Главная», «Меню», «Контакты») с помощью JavaScript.
   **Дизайн и стилизация:** Подключен нестандартный шрифт `Montserrat` через Google Fonts. Настроен фон, hover-эффекты для кнопок и стили заголовков.
   **Активная вкладка:** При клике на кнопку ей присваивается класс `.active`, который визуально выделяет текущую вкладку (коричневый фон, белый текст).
Уровень 2. Работа с контентом и данными
   **Данные из JSON:** Меню кафе генерируется динамически из файла `menu-data.json` с помощью цикла `forEach`.
   **Изображения блюд:** В карточки меню добавлены фотографии, которые загружаются по прямым ссылкам.
   **Бронирование:** На вкладке «Контакты» реализована кнопка «Забронировать столик», которая вызывает всплывающее окно (`alert`) с подтверждением.
